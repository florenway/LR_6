# Товары

Небольшое приложение: локальная база SQLite с категориями и товарами.

Студент: Волошенко Кирилл Андреевич  
Группа: Т-433901-ИСТ

## Что внутри

- Файл базы `shop.db`, таблицы `categories` и `products`.
- При первом запуске туда записываются тестовые товары.
- На главном экране ФИО, группа и кнопки категорий. Кнопки читаются из базы, а не прописаны по одной в разметке. Сейчас категорий четыре: Еда, Одежда, Игрушки, Канцтовары.
- По нажатию на категорию открывается список ее товаров: название, описание, цена.

## Как запустить

1. Android Studio → Open и выбрать эту папку.
2. Дождаться окончания Gradle Sync. Нужен SDK 34.
3. Запустить конфигурацию `app` на эмуляторе или телефоне (минимум Android 7, API 24).

Если после правок тестовых данных на экране остались старые строки, приложение надо удалить с устройства и поставить заново: файл базы создается только один раз.
